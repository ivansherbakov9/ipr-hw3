# ДЗ 3. Docker

Приложение со счетчиком, запущенное через Docker Compose. Для хранения данных используется redis.

**Запуск**

```bash
docker compose up -d --build
```

Приложение доступно по адресу http://127.0.0.1:8080/.

**Настройки**

Порт и приветствие задаются в файле `.env`. Пример настроек есть в `.env.example`.

**Проверка**

Получить значение счетчика:

```bash
curl http://127.0.0.1:8080/
```

Увеличить счетчик:

```bash
curl -X POST http://127.0.0.1:8080/increment
```

Проверить состояние приложения:

```bash
curl http://127.0.0.1:8080/healthz
curl http://127.0.0.1:8080/readyz
```

**Хранение данных**

Счетчик хранится в redis. Для него подключен volume, поэтому после `docker compose down` и повторного запуска данные остаются.

**Остановка**

```bash
docker compose down
```

Результаты проверок находятся в `REPORT.md`
